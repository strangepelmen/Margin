🚀 Пошаговая настройка (3 шага)
Шаг 1. Создание облачной базы данных (Supabase)
Зарегистрируйтесь на сайте supabase.com.

Нажмите «New project», укажите любое имя проекта и задайте пароль к базе данных (сохраните его себе).

Перейдите слева в вкладку Database.

Сверъу нажмите на зеленую кнопку Connect

В появившемся окне вверху выберите Direct и потом в Connection Method выберите Session Pooler и Type Url


Скопируйте строку подключения и вставьте в неё ваш реальный пароль вместо [YOUR-PASSWORD].

(Пример: postgresql://postgres.xxxx:mypassword@aws-0-eu-central-1.pooler.supabase.com:5432/postgres).

Шаг 2. Развертывание веб-приложения (Vercel)
Зарегистрируйтесь на vercel.com (через GitHub).

Создайте репозиторий в гитхаб

Загрузите файлы проекта в свой репозиторий на GitHub.

На Vercel нажмите «Create project» ➔ И импортируете ваш репозиторий, если нету ваших репозиториев и пишет установить гит нажмите инсталл и в появившемся окне тоже инсталл

В пункте Framework Preset выберите FastAPI.

Откройте блок Environment Variables (Переменные среды) и добавьте 2 параметра:

DATABASE_URL — ваша строка подключения из Шага 1.

BOT_TOKEN — 8724509159:AAHYfiKZEQMd49_sF1ItmV4AnUigx23ckDg

Нажмите Deploy.

После завершения деплоя скопируйте полученную ссылку на сайт (вида [https://ваш-проект.vercel.app](https://ваш-проект.vercel.app)).

Шаг 3. Запуск бота (ПК / VPS)
Убедитесь, что на компьютере установлен Python 3.10+.

Откройте папку с проектом в консоли / терминале.

Установите зависимости:

Bash
pip install -r requirements.txt
playwright install chromium
Откройте файл .env в папке проекта и заполните его:

Code snippet
BOT_TOKEN=8724509159:AAHYfiKZEQMd49_sF1ItmV4AnUigx23ckDg
WEBAPP_URL=https://ваш-домен-из-шага-2.vercel.app
DATABASE_URL=ваша_строка_supabase_из_шага_1
Запустите бота:

Bash
python main.py
